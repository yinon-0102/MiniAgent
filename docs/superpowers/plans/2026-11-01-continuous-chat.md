# 连续对话实现计划

**目标：** 完成已经确认的前三步：终端连续对话、最小会话命令、日志与异常恢复。

**边界：** 不实现 s08 压缩、会话落盘、流式输出、后台并发或新界面。不改变模型配置和权限规则。

**结构：** `main.py` 负责外层输入循环；`agent.py` 保持模型与工具的内层循环。当前会话复用消息列表和独立任务清单，`/new` 同时清空两者，保留系统提示词。配置、客户端、技能和工具只组装一次。
