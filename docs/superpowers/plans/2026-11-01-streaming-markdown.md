# 真流式与终端 Markdown 实现计划

用户已确认采用真正的流式响应，并用 Rich Live 累计渲染 Markdown。

1. 为客户端添加流式测试：片段即时回调、多工具参数拼接、usage、断流及资源关闭、非流式兼容。
2. 实现客户端流式接收；返回统一的 ChatCompletion，Agent 无需改变工具执行协议。不完整响应不执行工具，不自动重试。
3. 增加独立 TerminalOutput：交互终端限频刷新 Markdown；重定向输出逐片段写入纯文本；退出上下文时关闭 Live。
4. Agent 每次模型请求使用独立输出上下文，关闭后再输出日志；主入口避免重复打印。子 Agent 默认仅收集流，不显示其正文。
5. 增加集成测试，覆盖工具多轮、异常和历史消息；运行现有测试、终端显示验证。
6. 添加 rich 依赖，启用当前 .env 的 LLM_STREAM，更新 README 与中文注释。

已知基线：38 个测试中有 1 个失败，原因是旧测试期望的“模型输出>”和当前代码“模型输出 >”不一致；本次统一输出标签后更新对应断言。
