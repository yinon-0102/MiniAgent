# MiniAgent

跟随 learn-claude-code 学习机制的本地 Agent，当前支持终端连续对话。

## 启动

Windows 全局命令：将本项目的 `bin` 目录加入用户 PATH 后，重新打开 PowerShell，即可在任意目录运行：

```powershell
miniagent
```

启动脚本自动使用项目的 `.venv\Scripts\python.exe`，无需激活虚拟环境。
程序以本项目目录为工作目录，退出后保留终端原来的目录。
移动项目后，需要更新 PATH 中的 `bin` 路径。

在项目目录中激活已配置的虚拟环境，运行：

```powershell
python main.py
```

如果 `python` 命令不可用，也可在项目目录直接运行：

```powershell
& .\.venv\Scripts\python.exe main.py
```

直接输入问题，按回车发送。任务结束后会再次显示 `你 >`，可以继续追问。
同一会话保留用户消息、模型回答、工具结果和任务清单；配置和工具只初始化一次。

| 输入 | 行为 |
| --- | --- |
| `/help` | 查看帮助 |
| `/new` | 清空聊天历史和任务清单，保留系统提示词，不修改项目文件 |
| `/exit` | 退出程序，也支持 `q`、`quit`、`exit` |
| 空输入 | 继续等待，不调用模型 |

## 中断与异常

- 等待问题输入时，Ctrl+C 或输入结束会退出程序。
- 模型请求或工具执行中出现异常、Ctrl+C 时，停止本次任务并回到输入提示。
- 权限确认处保留原规则：Ctrl+C 或输入结束按拒绝当前操作处理。
- 保留已完成的工具结果，为失败和未执行的工具调用补齐对应消息，不自动重试。
- 已执行的文件或命令操作不会自动撤销；外部命令是否仍在运行需要另行核实。
- 请求失败后的运行状态会写入历史，模型不会被告知任务已经成功。

## 流式输出与 Markdown

安装或更新依赖：`& .\.venv\Scripts\python.exe -m pip install -r requirements.txt`。

默认启用真实流式响应，模型生成文本时终端同步显示；`.env` 中设置
`LLM_STREAM=true` 开启，`LLM_STREAM=false` 切回完整响应模式。
修改配置后需要重启 MiniAgent。

交互终端使用 Rich 渲染 Markdown，支持标题、列表、表格与代码高亮。
流式期间约每秒刷新 10 次，未闭合的代码块或表格会随内容到达调整排版，结束时完整渲染。
输出到管道或文件时逐片段输出原始 Markdown，不写入终端控制符。

工具名称及 JSON 参数按分片累计，整轮正常结束后才执行工具；子 Agent 同样接收流式响应，
但只向父 Agent 返回完整结果，不直接显示子 Agent 正文。
断流、输出被截断或 Ctrl+C 时关闭流连接，不执行本轮未完成的工具请求、不自动重试。
已展示的部分文本保留在终端，不作为完整模型回答加入历史；下一次输入可继续对话。

`[结束日志]` 中的耗时与请求次数只统计本次 Agent 运行，不包含等待下一次提问的时间。
`[上下文统计]` 显示当前历史中的工具结果数量，包含之前的任务。

当前会话只保存在内存里，退出即结束；s08 上下文管理、保存恢复和新界面尚未接入。
