# Python 代码审查

## 工作步骤

1. 读取用户指定的文件，明确代码用途、输入和输出。
2. 检查边界条件、异常处理和可能的逻辑错误。
3. 必要时读取相关调用代码和测试，核实问题是否成立。
4. 只报告有依据的问题，区分确定的缺陷与待确认的疑点。
5. 默认只做审查，用户要求修复时再修改代码。

## 输出要求

按以下顺序组织结果：

- 审查结论。
- 发现的问题：说明文件、函数、触发条件和影响。
- 建议补充的验证。

没有发现明确缺陷时如实说明，不要为了凑数量编造问题。
